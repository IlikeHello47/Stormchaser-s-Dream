**Stormchasers Dream** is an advanced, high-fidelity severe weather and meteorology mod built from scratch using the **NeoForge** ecosystem for Minecraft 1.21.1.

Unlike traditional vehicle mods, **this mod does not simply add pre-built cars.** Instead, it introduces a modular ecosystem of engineering blocks. These specialized components allow you to convert Sable-based moving vehicles into heavy-duty, field-ready Stormchasing units capable of intercepting atmospheric monsters.

---

## 🚀 Core Features Roadmap

### 📊 Meteorology & Tracking Tools
- [ ] **Doppler Radar Systems:** Handheld and vehicle-mounted displays showing real-time precipitation and storm rotation hooks.
- [ ] **Data Gathering Instruments:** Working anemometers, barometers, and weather balloons to track thermodynamic changes and wind vector forces.

### 🌀 Dynamic Severe Weather
- [ ] **Supercell Formations:** Evolving cloud layers featuring rolling wall clouds, shelf clouds, and visible atmospheric rotation.
- [ ] **Volumetric Tornadoes:** Physics-driven funnel clouds scaling from weak EF0 ropes to catastrophic EF5 wedges capable of lifting blocks and entities.

### 🛠️ Modular Chaser Engineering (No Pre-built Cars!)
- [ ] **Reinforcement Blocks:** Heavy armor plating to protect vehicle structures from flying debris and hail damage.
- [ ] **Airbag Suspension Wheel Mounts:** Specialized utility mounts allowing vehicles to handle extreme terrain and shockwaves near high-wind areas.
- [ ] **Side Spikes & Anchors:** Deployable mechanical spikes to lock your vehicle firmly onto the terrain, preventing catastrophic lift during a direct tornado intercept.

## 💻 Developer Setup & Environment

To contribute to the codebase or run local test environments, ensure you have **Java JDK 21** installed and configured.

### Quick Start Guide

1. **Clone the Repository**
   ```bash
   git clone https://github.com
   ```

2. **Import via Gradle**
   Open your preferred IDE (highly recommended: **IntelliJ IDEA**). Select *Open*, choose the cloned project root folder, and allow Gradle to automatically sync and download all Minecraft/NeoForge dependencies via `build.gradle`.

3. **Launch the Sandbox**
   Run the following Gradle task to launch your local testing client:
   ```bash
   ./gradlew runClient
   ```
